# NanoString GeoMx DSP spatial transcriptomic analysis

## Description
Code supporting the spatial transcriptomic analysis of rTG4510 mouse tissue samples. Data was generated using the NanoString (now Bruker Spatial Technologies) GeoMx Digital Spatial Profiler.

This analysis is based upon this previously available workflow: https://github.com/DavisLaboratory/GeoMXAnalysisWorkflow.

The main workflow file for this projct is [Nanostring.R](https://github.com/fergusfones/PTY24/blob/Workflow/Nanostring.R)

## Result
This project has concluded

Neuronal cell populations processed by the NanoString GeoMx DSP were found to be contaminated with astrocytic cells. This was a characteristic of the tauopathy of the tissue profiled. However, controlling for cell type proportions allows for a pure neuronal population which can be used in differential expression analysis and other downstream analyses.
